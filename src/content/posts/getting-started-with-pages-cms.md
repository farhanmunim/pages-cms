## 1. Sign in

Go to [app.pagescms.org](https://app.pagescms.org), sign in with GitHub and open this repository.

## 2. Create a post

Open **Content → Posts** and click **Add an entry**. Fill in the title, pick an author, some categories and tags, and write the body in the rich-text editor.

## 3. Publish

Set **Status** to *Published* and save. Pages CMS commits the file to the repository and Cloudflare Pages rebuilds the site automatically.
