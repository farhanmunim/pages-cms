## How this site works

Content is written in **Pages CMS**, committed straight to the Git repository, and built into a static website by **Astro**. Every commit triggers a new build on **Cloudflare Pages**.

- No database
- No paid services
- Version history is the Git history

> "The best CMS is the one that gets out of your way."

Rich text supports headings, bold and *italic* text, lists, links like [pagescms.org](https://pagescms.org), quotes and inline images:
